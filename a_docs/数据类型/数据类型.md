# redis中的数据类型
- string
    - 特点:最基本类型，二进制安全，可存储字符串、整数、浮点数
    - 场景：缓存、计数器、分布式锁、简单key/value存储
    - 常用命令: set、get、incr、decr、append、strlen
- hash
    - 特点: key/val集合、适合存储对象、节省空间。
    - 场景: 存储用户信息、商品详情、配置等结构化数据。
    - 常用命令: hset,hget,hmset,hmget,hgetall,hdel
- list
    - 特点: 有序字符串列表，支持两端插入和删除，可作为栈和队列
    - 场景: 消息队列、最新消息列表、排行榜
    - 常用命令:lpush,rpush,lpop,rpop,lrange,llen
- set
    - 特点:无序字符串集合、不允许重复元素、支持交、并、差集合操作
    - 场景: 标签系统、好友关系、共同关注、去重
    - 常用命令: sadd,smembers,sismember,sinter,sunion,srem
- zset
    - 特点: 有序字符串集合、不允许重复、每个元素关联一个score按该字段排序
    - 场景: 排行榜、延时队列、范围查询
    - 常用命令: zadd,zrange,zrevrange,zscore,zincrby,zerm
- bitmap
    - 特点: 二进制bit集合、适合存储布尔值节省空间
    - 场景: 标签记录、在线状态、权限控制
    - 常用命令: setbit,getbit,bitcount,bitop
- geo
    - 特点:存储地理位置、支持距离计算和范围查询
    - 场景: 附近的人、商家定位、地理围栏
    - 常用命令: geoadd,geodist,georadius,geopos
- hyperloglog
    - 特点: 用于统计集合中不重复元素的个数，占用空间小，适合大数据量统计。
    - 场景: 网站访问量（UV）统计、用户行为分析。
    - 常用命令: pfadd,pfcount,pfmerge
